# Comparison

Each corpus case drawn by mermaid.js and by STM, rasterized in the same headless Chromium with the same font. The
score is their structural similarity, and a case passes L4 when it reaches its type's threshold. CI adds a snapshot
after each push to main, so each case keeps the history of STM's drawing.

Pick a type to see its cases. On a case, "Report a difference" opens a GitHub issue with the case filled in.
